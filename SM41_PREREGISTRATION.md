# SM41 pre-registration

Before any SM41 model evaluation: test only F2 first, adding two deterministic cloud-adjusted clear-sky proxies to the existing rich site model. Formula: `ghi_cs * (1 - 0.75 * (clip(cloud,0,100)/100)**3.4)` separately for WA and WB; this is a fixed empirical proxy, not measured irradiance. Values missing remain missing. No tuning on either validation year. `site_code` removed, seed 7, two years, ext none, same SM39 group model and alpha 0.2. Compare W against SM40 using observed-only scoring. Select family for forward evaluation only if 2023 W decreases. If selected, evaluate 2024 once; no post-2024 formula changes. Final adoption additionally requires improvement both years, 7-day 5000 paired bootstrap upper bound <0, no full month deterioration >5%, complete valid submission and reproducibility. A failed criterion retains SM40. Months with effectively zero baseline W should be disclosed rather than treated as meaningful percentage comparisons. Multi-seed only after family screening, subject to resources. 2023 coverage and repeated use of 2024 limit inference.
